<얼굴의 어떤 규칙을 픽셀값 0~255으로 어떻게 코드에 쓸 수 있나>
1. 명암의 대비 규칙 : 특정 영역의 픽셀 평균값을 서로 빼서 그 차이가 기준치(임계값)를 넘는지 검사하는 방식

(밝은 영역 픽셀 평균) - (어두운 영역 픽셀 평균) > 기준값 이면 얼굴 규칙 성립

예시 :
import numpy as np

# 20x20 크기의 가상의 얼굴 이미지 행렬 (0~255 값)
# 실제로는 cv2.imread()로 불러온 흑백 이미지 행렬입니다.
face_matrix = np.random.randint(0, 256, (20, 20), dtype=np.uint8)

# 규칙 정의: [행 5~10, 열 2~8]은 왼쪽 눈 영역 (A: 어두워야 함)
#            [행 5~10, 열 9~15]는 콧등 영역 (B: 밝아야 함)
eye_area = face_matrix[5:10, 2:8]
nose_area = face_matrix[5:10, 9:15]

# 두 영역의 픽셀 평균값 계산
eye_mean = np.mean(eye_area)
nose_mean = np.mean(nose_area)

# 코드로 규칙 검사 (명암 차이가 50 이상 나면 "눈과 코의 구조"라고 판단)
if (nose_mean - eye_mean) > 50:
    print("얼굴의 눈-코 명암 규칙을 만족하는 영역을 찾았습니다!")
else:
    print("얼굴이 아니거나 명암 조건이 맞지 않습니다.")

2. 주변 픽셀과의 대소 비교 규칙 코딩하기 (LBPH)
"https://stroy-jy.tistory.com/105" 이 경로에서 찾음
얼굴의 피부 질감이나 미세한 굴곡(눈썹 경계, 입술 선 등) "중심 픽셀보다 주변 픽셀이 더 밝은가/ 어두운가"의 이진 패턴 (0과 1로)으로 규칙화하기

기준 픽셀 값보다 주변 픽셀 값이 크거나 같으면 1, 작으면 0으로 치환

예시 :
import numpy as np

# 얼굴 이미지 내부의 3x3 픽셀 행렬 예시 (블로그 본문 데이터)
# [12, 15, 18]
# [ 5,  8,  3]
# [ 8,  1,  2]
pixel_3x3 = np.array([[12, 15, 18],
                      [ 5,  8,  3],
                      [ 8,  1,  2]])

center_value = pixel_3x3[1, 1]  # 정중앙 값인 '8'을 기준 규칙으로 잡음

# 코드로 0과 1의 바이너리 마스크(행렬) 생성 규칙 적용
# center_value(8)보다 크거나 같으면 1, 작으면 0
binary_matrix = np.where(pixel_3x3 >= center_value, 1, 0)

print(binary_matrix)
# 출력 결과:
# [[1, 1, 1],
#,
#]
# 이 0과 1의 조합 패턴 규칙을 통해 얼굴의 고유한 지문(히스토그램)을 만들어 냅니다.


3. 급격한 색상 변화(경계선) 규칙 코딩하기 (소벨 필터 원리)
얼굴의 턱선이나 입술 테두리는 픽셀 값이 갑자기 급격하게 변하는 규칙
(예시 : 턱 내부 피부색 210 -> 턱 바깥 배경색 40) 이웃한 픽셀 값을 서로 뺏을 때 그 차이값 (미분값)이 거대해지는 점을 찾는 코드

abs(현재 픽셀 값 - 바로 오른쪽 픽셀 값) = 변화량

예시 :
import numpy as np

# 가로로 1줄짜리 픽셀 배열이 있다고 가정 (얼굴 턱선 경계를 지나가는 중)
# [피부, 피부, 피부, 턱선경계, 배경, 배경]
face_line = np.array([210, 215, 208, 120, 45, 40])

# 이웃한 픽셀 간의 차이를 계산하는 코드
pixel_diff = np.abs(face_line[:-1] - face_line[1:])

print(pixel_diff) 
# 출력 결과: [ 5,  7, 88, 75,  5]
# 픽셀 값이 208에서 120으로, 다시 45로 급변한 구간에서 차이값(88, 75)이 튑니다.

# 코드로 규칙 적용: 변화량이 50을 넘는 인덱스를 '얼굴의 윤곽선 규칙'으로 지정
edge_indices = np.where(pixel_diff > 50)[0]
print(f"얼굴의 윤곽선 경계 규칙이 발견된 픽셀 위치: {edge_indices}")
